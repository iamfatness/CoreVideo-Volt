# Rundown

Status: after the library is usable. This is the newsroom for a crew that does not have one.

## Job

An ordered list of items. Each item points at spans. Script text lives on the item, not on the asset.

## In scope

- Show, item order, slug, script, status: ready, next, on air, aired, killed.
- Attach and detach spans.
- Manual "take this span to program" through CoreVideo. This is a button, not the clock.
- Rights check on attach. A held span can be attached and cannot be aired.
- MOS is an export later. Profile 1 object, then Profile 2 running order. Not the editor.

## Out of scope

Assignments, wires, approvals, a second NRCS, prompter, MOS item control.

## Acceptance

- A producer can build a show from spans without leaving Volt.
- Reorder does not copy media.
- Killing an item does not delete the asset.
- A station with ENPS is not required for the show to exist.

## Depends on

Library spans. CoreVideo take, for the manual button only.
