# Product brief

Status: planning. Name: Volt. Family line: CoreVideo Volt.

## The gap

On one end are the legacy suites: Dalet, Avid MediaCentral, Viz One, and a Ross or Grass Valley stack beside them. Huge feature lists, rough usability, architecture from a plant that no longer exists, and a sales process that is the product. The bill is the integrator.

On the other end are point tools. A library, a newsroom, a packager, a switcher. Each one is fine. None of them share an ID unless somebody writes the glue.

Volt is the wing those crews cannot buy. One software chain from the recording to air and publish.

## Who it is for

A crew that can expense a software license and cannot expense a systems integrator.

- Sports desks and in-arena shows
- Houses of worship
- College and regional production
- Corporate studios
- A regional news desk that is one truck and a handful of seats

Not a network origination center. Not a film studio archive.

## The session

The product is one session, not five modules with a shared login. Record, find, mark, cue, and publish happen on the same asset ID without a handoff.

A TD stays in Volt for the show. CoreVideo is the room the session lives in: program, clean, ISO, PTZ, graphics, audio snapshots. A recording started on program or an ISO mints the ID. A proxy exists before wrap. Publish is an output target, the same way a stream is.

## What Volt owns

| Function | What the crew gets |
|---|---|
| Ingest | Cards, SRT, NDI, program and ISO. ID minted while the file is growing. Checksum and technical metadata on the same job. Proxy before wrap. |
| Library | Essences, spans, transcript, rights, versions. Search returns a span, not a file. |
| Rundown | Stories, items, and spans in running order. Script text lives here. This is the newsroom for a crew that does not have one. |
| Playout | Software playout of those items to program, with secondary events. The clock lives here. |
| Studio automation | The rundown cues the room CoreVideo already controls: inputs, PTZ presets, graphics, audio snapshots. |
| Publishing | An approved item becomes the house file, the OTT package, and the social cut. As-run and the URL write back to the same item. |

## What stays outside

- A hardware master-control switcher. A Grass Valley or Imagine frame is an output, not the scheduler.
- MOS as the product. MOS Profile 1 and 2 are an export for a station that already has ENPS, iNews, or Octopus.
- An MXF muxer, an LTO driver, a loudness library, IMF packaging.
- A second editor. Premiere and Resolve get a panel that resolves the ID.

## Pitch

Not "we do what Dalet does." The clip is in the system before the period ends, and the crew did not buy five tools to make that true.

## Name

Volt is the hit that takes the show to air. CoreVideo stays the switcher and the suite line. The invoice can read CoreVideo Volt. The box, the tab, and the trademark say Volt.

Rejected on purpose: Bin, Control, Media, Orchestra, MOS, Call, Desk. Control and Orchestra are category words already taken. Media is a company. Call is vMix Call, a guest return. Desk is furniture.
