# Start here

Build in this order.

1. Control plane objects. Asset, essence, span, job. Done.
2. MAM ingest and library search. Done as a contract.
3. Storage promote and open-file wrap. Done as a contract.
4. Proxy transcode. Done as a contract.
5. Orchestration rundown and cue records. Done as a contract.
6. Distribution versions. Done as placeholders.
7. Speech worker, deliverable files, Postgres, CoreVideo dispatch, playout clock.

The session shell lists assets, seeks a proxy from a search hit, and shows publish URLs on a rundown item.
